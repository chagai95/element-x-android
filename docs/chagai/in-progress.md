# In progress: a properly loud alarm with its own tones

Branch: `chagai/feat/a-properly-loud-alarm-with-its-own-tones`
Started: 2026-10-13

## What it should do

Make a call reminder ring like a real alarm clock, not like a notification.

- A foreground service owns the sound, so it can be as loud as it needs to be.
- The alarm stream goes to maximum for the duration and is put back afterwards.
- Five original tones, generated by `tools/chagai/make_tones.py`, plus the phone's own.
- Fade-in, repeating vibration waveform, optional torch blink.
- Do Not Disturb bypass once the user grants notification-policy access.
